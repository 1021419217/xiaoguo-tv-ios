# 界面改造 · 约定（每次改动前先读这一页）

这份文件是唯一依据。与聊天记录冲突时以本文件为准；要改规则先改这里。

## 一、已经定死的规则

1. **列数按屏宽**：手机竖屏 3 列，手机横屏 2 列。
2. **横竖混排的源**：走瀑布流，**固定 2 列**（不再扩展其它页面/其它列数说法）。
3. **封面**：一律裁切填满（`BoxFit.cover`），不出现上下或左右黑边。
4. **主题色**：跟随「设置 → 外观」选的色，**不许全局覆盖 `scheme.primary`**。
5. **底栏**：贴底，圆角只在上边，不留底部死黑。
6. **混合判定**：`CoverShapes.isMixed` 门槛 4 张，避免个别横图把竖屏源误判。

## 三、本轮做法（留档）

1. **详情页封面闪 + 糊**
   - `cover_image.dart` 同一封面只用一处 `CoverImage` 和一个 Key，删掉叠在下面的模糊副本，不再重复解码。
   - 已下载封面用同步路径首帧直接出图，进出详情不再先空一帧再淡入。
   - 封面按剧集 id 记住本地文件，站源修正封面地址后也不会重复下载、不会先空一帧。
   - 手机详情大海报接入 `heroScope: 'drama'`，列表封面直接飞到大海报位置。
   - 详情页大封面按实际显示尺寸解码（列表仍用 440），大图解码完成前先铺已经缓存的小图。
2. **设置页行卡 + 顶栏动作图标化 + 区标题**
   - 设置行：圆角方形图标、去掉分隔线、行高 56；图标统一中性底色。
   - 顶栏动作：文字（编辑/清空/清除已结束）收成 38 圆形图标。
   - 区标题：12px 灰、字距，右侧「全部 ›」（有源筛选时出现，点了回到全部）。
3. **混合源瀑布流铺到追剧 / 历史 / 下载**
   - 三个页面接入同一套 `usePosterMasonry` 判定，固定两列，按封面实际比例排版。
4. **主/次按钮形态统一**
   - 主：主题色实底胶囊，一屏一个（详情页的播放）。
   - 次：描边胶囊，与主按钮同高（追剧、下载、合并、导出）。
5. **底栏与留白**
   - 底栏贴底、只上边两角圆，底色用主题表面色，安全区一起铺满；选中态去掉大色块，只换图标/文字颜色。
   - `pageBottomInset`：底栏高度 + 系统手势区 + 16 收尾，各 tab 页统一按它收底。
6. **启动白屏**
   - iOS `LaunchScreen.storyboard` 背景与 `LaunchImage` 改纯黑；Android `launch_background` 与 `windowBackground` 改纯黑。

## 四、禁止事项

- 不再新增设计方向（A/B/C、卡片压封面等已作废）。
- 不改封面比例、不重做内容卡片。
- 不中途单独出包：待办全部完成→`dart analyze lib`→一次构建→一次交付。
- 构建失败先看日志里的 `lib/xxx.dart:行: Error:`，不要相信 Flutter 末尾的签名提示。

## 五、方法论（unslop）

界面改造按 `docs/unslop/SKILL.md` 的流程走：先写五行方向（Product / Character / World / Moments / Signature），再按 9 个 pass 改——**间距 → 颜色 → 图标 → 文案 → 字体 → 布局 → 细节 → 视觉 → 动效**，每个 pass 收完再进下一个。

它点名的 AI 味必须在改的过程中删掉：紫色渐变、发光、渐变文字、emoji 当图标、喊口号式文案、间距不齐、胶囊泛滥。

当前方向：深夜放映室（黑场、安静外壳），只有「正在播」一处允许出现强调色。
