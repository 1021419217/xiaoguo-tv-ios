# 界面改造 · 约定（每次改动前先读这一页）

这份文件是唯一依据。与聊天记录冲突时以本文件为准；要改规则先改这里。

## 一、已经定死的规则

1. **列数按屏宽**：手机竖屏 3 列，手机横屏 2 列。
2. **横竖混排的源**：走瀑布流，**固定 2 列**（不再扩展其它页面/其它列数说法）。
3. **封面**：一律裁切填满（`BoxFit.cover`），不出现上下或左右黑边。
4. **主题色**：跟随「设置 → 外观」选的色，**不许全局覆盖 `scheme.primary`**。
5. **底栏**：贴底，圆角只在上边，不留底部死黑。
6. **混合判定**：`CoverShapes.isMixed` 门槛 4 张，避免个别横图把竖屏源误判。

## 二、待办（全部做完只构建一次）

3. **混合源瀑布流铺到追剧 / 历史 / 下载**

4. **主/次按钮形态统一**
   - 主：主题色实底胶囊，每屏一个。
   - 次：描边胶囊，与主按钮同高。

## 三、禁止事项

- 不再新增设计方向（A/B/C、卡片压封面等已作废）。
- 不改封面比例、不重做内容卡片。
- 不中途单独出包：待办全部完成→`dart analyze`→一次构建→一次交付。
- 构建失败先看日志里的 `lib/xxx.dart:行: Error:`，不要相信 Flutter 末尾的签名提示。
